# Odin Recipes

A simple multi-page recipe site built for The Odin Project Foundations curriculum.

## What is included

- A home page at `index.html`
- Three recipe pages in `recipes/`
- Local SVG images for each recipe page
- Navigation links between the home page and each recipe page

## Project structure

```text
odin-recipes/
├── index.html
└── recipes/
	├── apple-pie.html
	├── chicken-parmesan.html
	├── lasagna.html
	└── images/
		├── apple-pie.svg
		├── chicken-parmesan.svg
		└── lasagna.svg
```

## How to use

Open `index.html` in a browser, then choose any recipe from the list.

## Notes

- Each HTML file includes the standard boilerplate.
- Each recipe page includes a home link for easy navigation.
